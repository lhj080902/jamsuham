잠수크래프트 클라우드 서버 (jamsu-cloud) v@VERSION@ — 설치 안내
======================================================================

처음 설치하는 분이 위에서부터 차례로 따라 하면 되도록 썼습니다.
윈도우와 리눅스가 같이 적혀 있으니 자기 컴퓨터에 맞는 쪽만 보시면 됩니다.

이 폴더에 들어 있는 것

  README.txt       지금 보는 설치 안내
  ASK-CLAUDE.txt   하다가 막혔을 때: 이 파일 내용을 통째로 클로드(https://claude.ai)에
                   붙여 넣고 물어보면 이 프로그램을 아는 상태로 도와줍니다
  docs/CLOUD.md    전체 설명서 (모든 설정 항목, 컴퓨터를 여러 대로 늘리는 법 등. 메모장으로 열립니다)
  bin/, lib/       프로그램 (건드리지 않습니다)


이 프로그램이 하는 일
----------------------------------------------------------------------
폰 대신 "이 컴퓨터"가 마인크래프트 서버에 접속해 있습니다(잠수).
사용자는 웹 화면이나 잠수크래프트 앱으로 그 잠수를 보고 채팅·조작합니다.
그래서 이 컴퓨터는 24시간 켜져 있어야 하고, 사용자들의 마이크로소프트 로그인 정보를
(암호화해서) 보관하게 됩니다. 믿을 수 있는 컴퓨터에만 설치하세요.

전체 순서

  1. 자바 17 설치
  2. 압축 풀기
  3. 한 번 실행해서 설정 파일 만들기
  4. 설정 파일에 client ID 적고 다시 실행
  5. 웹 화면에서 로그인해 보기
  6. 쓸 사람 등록하기 (프리미엄)
  7. 잠수 시작해 보기
  8. 인터넷에 공개하기 (HTTPS)   ← 다른 사람·폰 앱이 쓰게 하려면
  9. 앱에서 연결하기
 10. 컴퓨터를 켜면 자동으로 시작되게 하기

5번까지 되면 설치는 끝난 것입니다. 8번부터는 밖에서 쓰게 할 때 필요합니다.


1. 자바 17 설치
----------------------------------------------------------------------
자바 17 이상이 필요합니다. 이미 있는지 먼저 확인합니다.

  윈도우: 시작 메뉴에서 "cmd" 를 찾아 명령 프롬프트를 열고
  리눅스: 터미널에서

      java -version

  openjdk version "17.0.x" 처럼 17 이상이 나오면 2번으로 넘어갑니다.
  "java 는 내부 또는 외부 명령 ... 이 아닙니다" / "command not found" 가 나오거나 숫자가 17보다 작으면 설치합니다.

[윈도우]
  1) https://adoptium.net/temurin/releases/?version=17 을 엽니다.
  2) Windows / x64 / JRE 줄의 .msi 파일을 받아 실행합니다. (JDK 를 받아도 됩니다)
  3) 설치 화면의 항목 중 "Add to PATH" 가 켜져 있는지 확인하고 끝까지 설치합니다.
  4) 명령 프롬프트를 "새로" 열고 java -version 으로 확인합니다. (열려 있던 창은 새 설치를 모릅니다)

[리눅스 — 우분투·데비안]
      sudo apt update
      sudo apt install -y openjdk-17-jre-headless unzip

  다른 배포판은 그 배포판의 자바 17 꾸러미를 설치하면 됩니다.


2. 압축 풀기
----------------------------------------------------------------------
jamsu-cloud.zip 을 풀면 jamsu-cloud 폴더가 나옵니다. 이 폴더를 계속 둘 곳에 놓습니다.

[윈도우]  예: C:\jamsu-cloud
          (바탕 화면·다운로드 폴더보다, 지울 일이 없는 곳이 좋습니다)

[리눅스]  예: /opt/jamsu-cloud
      sudo unzip jamsu-cloud.zip -d /opt
      cd /opt/jamsu-cloud

아래의 모든 명령은 "jamsu-cloud 폴더 안에서" 실행합니다.
설정 파일(cloud.properties)과 데이터(data 폴더)가 명령을 실행한 그 자리에 생기기 때문입니다.


3. 한 번 실행해서 설정 파일 만들기
----------------------------------------------------------------------
[윈도우]
  1) 탐색기로 jamsu-cloud 폴더를 엽니다.
  2) 위쪽 주소 표시줄을 누르고 cmd 라고 적은 뒤 Enter → 그 폴더에서 검은 창(명령 프롬프트)이 열립니다.
  3) 아래를 입력합니다.

      bin\jamsu-cloud.bat

  주의: bin 폴더 안의 jamsu-cloud.bat 을 더블 클릭해서 켜지 마세요.
        그러면 설정 파일과 data 폴더가 bin 안에 따로 생깁니다.

[리눅스]
      cd /opt/jamsu-cloud
      bin/jamsu-cloud

  ("Permission denied" 가 나오면: chmod +x bin/jamsu-cloud )

이런 줄들이 나오면 정상입니다 (시각과 경로는 다릅니다).

      11-27 17:30:00 잠수크래프트 클라우드 서버 v@VERSION@
      11-27 17:30:00 설정 파일: C:\jamsu-cloud\cloud.properties
      11-27 17:30:00 데이터 폴더: C:\jamsu-cloud\data
      11-27 17:30:00 웹 주소: http://127.0.0.1:8787
      11-27 17:30:00 [경고] msClientId 가 비어 있어 마이크로소프트 로그인을 쓸 수 없습니다 (cloud.properties 에 적어 주세요)
      11-27 17:30:00 계정 0개

이제 Ctrl+C 를 눌러 끕니다.
(윈도우에서 "일괄 작업을 끝내시겠습니까 (Y/N)?" 라고 물으면 Y 를 누르고 Enter)

jamsu-cloud 폴더 안에 cloud.properties 파일과 data 폴더가 생겼는지 확인합니다.


4. 설정 파일에 client ID 적고 다시 실행
----------------------------------------------------------------------
마이크로소프트 로그인을 쓰려면 client ID 한 줄을 적어야 합니다.

  1) cloud.properties 를 엽니다.
       윈도우:  notepad cloud.properties
       리눅스:  nano cloud.properties
  2) msClientId= 로 시작하는 줄을 찾아 아래처럼 고칩니다. (잠수크래프트 앱과 같은 값입니다)

      msClientId=9f60141c-29ac-4d71-8fa1-f89e32a085e7

  3) 저장하고 닫습니다. (nano: Ctrl+O, Enter, Ctrl+X)
  4) 3번과 같은 명령으로 다시 켭니다. 이번에는 msClientId 경고 줄이 없어야 합니다.

다른 항목은 처음에는 그대로 두면 됩니다. 설정을 바꾼 뒤에는 껐다 켜야 적용됩니다.
항목 설명은 cloud.properties 안의 설명 줄과 docs/CLOUD.md 4번에 있습니다.


5. 웹 화면에서 로그인해 보기
----------------------------------------------------------------------
서버를 켜 둔 채로, "그 컴퓨터의" 브라우저에서 아래 주소를 엽니다.

      http://localhost:8787

  1) "마이크로소프트 계정으로 로그인" 을 누릅니다.
  2) 화면에 나온 코드를 복사하고, 안내된 마이크로소프트 페이지에 붙여 넣은 뒤 마인크래프트 계정으로 로그인합니다.
  3) 처음에는 보통 이런 안내가 나옵니다. 정상입니다 → 6번으로.

      (닉네임) 계정은 클라우드 잠수(프리미엄)를 쓸 수 있는 계정이 아닙니다.
      운영자에게 아래 닉네임을 알려 주세요.

화면(모니터)이 없는 리눅스 서버라면, 자기 PC 에서 아래처럼 연결해 두고 PC 의 브라우저로
http://localhost:8787 을 열면 됩니다. (또는 8번을 먼저 하고 그 주소로 들어갑니다)

      ssh -L 8787:127.0.0.1:8787 계정@서버주소

중요: 로그인 코드는 "그 계정의 주인이 직접" 입력해야 합니다.
      남이 보내 준 코드를 마이크로소프트 페이지에 입력하면 그 사람이 내 계정의 잠수를 조작할 수 있게 됩니다.


6. 쓸 사람 등록하기 (프리미엄)
----------------------------------------------------------------------
기본 설정에서는 운영자가 등록한 계정만 클라우드 잠수를 쓸 수 있습니다.
서버는 켜 둔 채로, jamsu-cloud 폴더에서 창을 하나 더 열어(3번과 같은 방법) 실행합니다.

  기한 없이 등록:
      윈도우:  bin\jamsu-cloud.bat grant 닉네임
      리눅스:  bin/jamsu-cloud grant 닉네임

  30일만 등록 (끝의 숫자가 일수):
      윈도우:  bin\jamsu-cloud.bat grant 닉네임 30

  빼기:
      윈도우:  bin\jamsu-cloud.bat revoke 닉네임

"프리미엄을 줬습니다: 닉네임 (기한 없음)" 이 나오면 된 것이고, 켜져 있는 서버에 바로 반영됩니다.
그 뒤 웹 화면에서 다시 로그인하면 들어가집니다.

- 이 명령도 반드시 jamsu-cloud 폴더 안에서 실행하세요. 다른 곳에서 실행하면 그 자리에 설정 파일과 data 가
  새로 생기고, 켜져 있는 서버에는 반영되지 않습니다.
- data\premium.txt 를 메모장으로 직접 고쳐도 됩니다 (한 줄에 한 명: 닉네임 또는 UUID, 그 뒤에 만료일. 저장하면 바로 반영).
- 닉네임은 바뀔 수 있으니 오래 쓸 사람은 UUID 로 적는 것이 안전합니다. (UUID 는 5번의 안내 화면에 같이 나옵니다)
- 등록 없이 로그인한 누구나 쓰게 하려면 cloud.properties 에서 premiumMode=open (권장하지 않음).


7. 잠수 시작해 보기
----------------------------------------------------------------------
웹 화면에서 서버를 추가하고(마인크래프트 서버 주소) 시작을 누릅니다.
채팅이 올라오면 성공입니다. 끊기를 누르면 멈춥니다.

알아 둘 기본 제한 (cloud.properties 에서 바꿉니다. 자세한 것은 docs/CLOUD.md 4번·10번)
  - 한 계정이 동시에 잠수할 수 있는 서버 수: 2        (maxSessionsPerAccount)
  - 같은 마인크래프트 서버에 동시에 들어갈 계정 수: 3   (maxAccountsPerTarget)
    모든 계정이 이 컴퓨터의 IP 하나로 접속하기 때문에 둔 제한입니다. 마인크래프트 서버마다
    "같은 IP 에서 몇 명까지" 규칙이 있어서, 무작정 늘리면 그 서버에서 이 IP 가 통째로 차단될 수 있습니다.
    운영진에게 허용을 받은 서버만 targetLimits 로 늘리세요.


8. 인터넷에 공개하기 (HTTPS)
----------------------------------------------------------------------
이 컴퓨터 밖에서(다른 사람의 브라우저, 폰 앱) 쓰게 하려면 HTTPS 주소가 꼭 필요합니다.
로그인 정보와 채팅이 오가기 때문에, HTTPS 없이 포트를 그대로 인터넷에 열면 안 됩니다.
cloud.properties 의 bind=127.0.0.1 은 그대로 두고, 앞에 아래 둘 중 하나를 둡니다. 둘 다 도메인이 필요합니다.

[방법 A — Cloudflare 터널]  공유기 설정이 필요 없어서 집 컴퓨터에 편합니다.
  1) 도메인을 Cloudflare 에 연결합니다.
  2) 이 컴퓨터에 cloudflared 를 설치하고 터널을 만들어, 터널의 대상을 http://localhost:8787 로 지정합니다.
     (Cloudflare 안내: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/ )
  3) cloud.properties 에 아래 줄을 적고 서버를 다시 켭니다.

      clientIpHeader=CF-Connecting-IP

[방법 B — Caddy]  도메인 + 공유기에서 80·443 포트를 이 컴퓨터로 넘겨 주기(포트 포워딩).
  Caddyfile 에 아래처럼 적으면 인증서를 자동으로 받아 줍니다. clientIpHeader 는 기본값 그대로 둡니다.

      cloud.example.com {
          reverse_proxy 127.0.0.1:8787
      }

  (Caddy 안내: https://caddyserver.com/docs/quick-starts/reverse-proxy )

끝나면 https://내주소 로 들어가서 5번의 로그인 화면이 나오는지 확인합니다.
clientIpHeader 는 쓰는 방법에 맞는 것 하나만 적어야 합니다 (잘못 적으면 로그인 시도 횟수 제한이 제대로 걸리지 않습니다).


9. 앱에서 연결하기
----------------------------------------------------------------------
잠수크래프트 앱(v2.0.0 이상)에서

  1) 설정 → 클라우드 잠수 (프리미엄) → 주소에 https://내주소 입력 → 확인
  2) 아래 계정 줄의 "연결" → 안내를 읽고 "동의하고 연결"
     (앱 v2.0.0 이상에서 로그인한 계정만 됩니다. 그 전에 추가한 계정은 계정 관리에서 지우고 다시 로그인한 뒤 연결)
  3) 서버 설정에서 "클라우드에서 잠수" 를 켜고 저장 → 목록에 클라우드 표시가 붙습니다.
  4) 시작을 누르면 클라우드에서 접속하고, 채팅이 앱에 실시간으로 보입니다.

앱은 https:// 주소만 받습니다 (같은 공유기 안의 http://192.168.x.x 는 시험용으로만 허용).


10. 컴퓨터를 켜면 자동으로 시작되게 하기
----------------------------------------------------------------------
창을 닫거나 컴퓨터가 꺼지면 서버도 꺼집니다. 다시 켜면 잠수하던 서버에 2초 간격으로 이어서 접속합니다.
컴퓨터가 절전 모드로 들어가면 잠수가 끊기니 절전을 꺼 두세요.

[윈도우]  작업 스케줄러 → 기본 작업 만들기
            트리거:    컴퓨터 시작 시
            동작:      프로그램 시작
            프로그램:  C:\jamsu-cloud\bin\jamsu-cloud.bat
            시작 위치: C:\jamsu-cloud          ← 꼭 적어야 합니다 (설정 파일이 있는 폴더)

[리눅스 — systemd]  /etc/systemd/system/jamsu-cloud.service 파일을 만듭니다.

      [Unit]
      Description=Jamsucraft Cloud
      After=network-online.target

      [Service]
      WorkingDirectory=/opt/jamsu-cloud
      ExecStart=/opt/jamsu-cloud/bin/jamsu-cloud
      Restart=always
      User=jamsu

      [Install]
      WantedBy=multi-user.target

  User= 에는 이 프로그램을 돌릴 계정 이름을 적습니다. 그 계정이 /opt/jamsu-cloud 에 쓸 수 있어야 합니다.
  전용 계정을 새로 만든다면:

      sudo useradd -r -s /usr/sbin/nologin jamsu
      sudo chown -R jamsu /opt/jamsu-cloud

  켜기 (부팅 때 자동 시작 포함) / 상태 보기 / 로그 보기:

      sudo systemctl enable --now jamsu-cloud
      sudo systemctl status jamsu-cloud
      sudo journalctl -u jamsu-cloud -f


끄기 · 업데이트 · 옮기기
----------------------------------------------------------------------
끄기:      서버 창에서 Ctrl+C  (systemd: sudo systemctl stop jamsu-cloud)
           잠수 중이던 서버는 기억해 두었다가 다시 켜면 이어서 접속합니다.

업데이트:  1) 서버를 끕니다. (켜진 채로 파일을 바꾸면 오류가 납니다)
           2) 새 jamsu-cloud.zip 을 같은 자리에 덮어 풉니다.
              zip 안에는 cloud.properties 와 data 폴더가 없으므로 설정과 데이터는 그대로 남습니다.
           3) 다시 켭니다.
           새 버전은 https://github.com/lhj080902/jamsuham/releases 의 최신 빌드에 있습니다.

옮기기:    다른 컴퓨터로 옮길 때는 서버를 끄고 cloud.properties 와 data 폴더를 통째로 가져가면 됩니다.

메모리:    자바는 따로 정해 주지 않으면 컴퓨터 메모리의 1/4 까지만 씁니다. 잠수를 많이 돌릴 컴퓨터는
           실행 전에 늘려 줍니다 (16GB 컴퓨터라면 10g 정도).
             윈도우:  set JAVA_OPTS=-Xmx10g      (같은 창에서 이어서 bin\jamsu-cloud.bat)
             리눅스:  export JAVA_OPTS=-Xmx10g   (systemd 는 [Service] 에 Environment=JAVA_OPTS=-Xmx10g)


절대 하면 안 되는 것
----------------------------------------------------------------------
- data 폴더(특히 data\master.key, data\worker.key)를 남에게 보내거나 인터넷에 올리지 마세요.
  이 폴더가 새면 등록된 사용자들의 계정이 위험해집니다. 클로드에게 물어볼 때도 이 파일 내용은 붙여 넣지 마세요.
- HTTPS 없이 bind=0.0.0.0 으로 바꿔 인터넷에 그대로 열지 마세요. (같은 공유기 안에서 잠깐 시험할 때만)
- 계정마다 IP 를 바꿔 마인크래프트 서버의 "같은 IP 인원 제한"을 피하는 용도로 쓰지 마세요.
  서버 규칙 위반이고, 적발되면 사용자 계정이 정지됩니다. 이 프로그램에는 그런 기능이 없습니다.
- 다른 사람의 컴퓨터·호스팅에서 돌린다면 그 컴퓨터의 주인이 data 폴더를 볼 수 있다는 점을 알고 쓰세요.


자주 겪는 문제
----------------------------------------------------------------------
"java 는 내부 또는 외부 명령 ... 이 아닙니다" / "JAVA_HOME is not set and no 'java' command could be found"
    → 자바가 없거나 설치 뒤 창을 새로 열지 않았습니다. 1번.

"UnsupportedClassVersionError"
    → 자바가 17보다 낮습니다. 1번대로 17 을 설치하고 java -version 으로 확인.

"포트 8787 를 열 수 없습니다 (이미 다른 프로그램이 쓰고 있거나 서버가 이미 켜져 있음)"
    → 서버가 이미 켜져 있는지(다른 창, 자동 시작) 확인합니다.
      다른 프로그램이 그 포트를 쓰는 것이면 cloud.properties 의 port 를 다른 숫자로 바꿉니다
      (웹 주소와 8번의 터널·Caddy 대상도 같은 숫자로).

"msClientId 가 비어 있어 마이크로소프트 로그인을 쓸 수 없습니다" /
웹에서 "이 서버에는 마이크로소프트 로그인이 설정되어 있지 않습니다"
    → 4번. 고친 cloud.properties 가 "지금 켠 그 폴더"의 것인지 확인하세요
      (켤 때 나오는 "설정 파일:" 줄에 실제로 읽은 파일 경로가 나옵니다).

설정을 고쳤는데 그대로다 / 등록(grant)했는데 반영이 안 된다
    → 서버를 다른 폴더에서 켰을 가능성이 큽니다. "설정 파일:" 과 "데이터 폴더:" 줄의 경로를 보세요.
      설정을 고친 뒤에는 껐다 켜야 합니다 (premium.txt 만 바로 반영).

"(닉네임) 계정은 클라우드 잠수(프리미엄)를 쓸 수 있는 계정이 아닙니다"
    → 6번대로 그 닉네임을 등록합니다.

"마이크로소프트 로그인 서버에 연결하지 못했습니다" / "마이크로소프트 로그인에 실패했습니다: ..."
    → 이 컴퓨터의 인터넷 연결·방화벽을 확인합니다. 계속되면 화면의 문구 전체를 개발자에게 보내 주세요.

"로그인 시간이 지났습니다. 처음부터 다시 해 주세요"
    → 코드를 받은 뒤 너무 오래 걸렸습니다. 로그인 버튼부터 다시.

다른 컴퓨터·폰에서 http://이컴퓨터주소:8787 이 안 열린다
    → 정상입니다. 기본 설정(bind=127.0.0.1)은 이 컴퓨터 안에서만 열립니다. 밖에서 쓰려면 8번.

앱에서 주소를 넣었는데 연결이 안 된다
    → https:// 로 시작하는 주소인지, 폰의 브라우저로 그 주소가 열리는지 먼저 확인합니다.

"지금 이 서버는 클라우드 자리(3개)가 모두 찼습니다. ..."
    → 같은 마인크래프트 서버에 들어갈 수 있는 계정 수(maxAccountsPerTarget)가 찼습니다. 7번의 설명 참고.

"지금 클라우드 서버가 가득 찼습니다"
    → 전체 잠수 수(maxActiveSessions)가 찼습니다. 컴퓨터 사양이 되면 늘립니다.

잠수가 "다른 클라이언트(PC 게임 등)" 때문에 끊겼다고 나오며 멈춘다
    → 같은 계정으로 PC 게임 등에 들어가면 마인크래프트 서버가 한쪽을 내보냅니다. 정상 동작입니다.
      (30분 안에 다시 시작하면 "그쪽 접속이 끊깁니다. 계속할까요?" 를 묻습니다)

서버가 저절로 꺼진다
    → 메모리가 바닥나면 스스로 꺼지게 되어 있습니다. 위의 "메모리" 대로 늘리고, 10번의 자동 시작을 설정해 두세요.
      창을 닫았거나 원격 접속(SSH)을 끊어도 꺼집니다 → 10번.

로그에 한글이 깨져 보인다 (리눅스에서 파일로 저장한 로그 등)
    → 로그는 UTF-8 입니다. UTF-8 로 여는 편집기로 보세요.
