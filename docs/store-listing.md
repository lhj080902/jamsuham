## 2. 앱 콘텐츠 신고

**광고**: 광고 없음

**앱 액세스 (심사자 로그인 안내)**: "일부 기능이 제한됨"을 선택하고 아래처럼 적습니다.
```
로그인 없이 모든 기능을 확인할 수 있습니다.
1. 첫 화면 + 버튼 → 서버 주소에 공개 마인크래프트 자바 서버 주소 입력 (예: 비정품 접속을 허용하는 테스트 서버)
2. 계정 → "비정품 닉네임"으로 아무 영문 닉네임 추가
3. 접속 버튼 → 잠수 시작, 알림이 뜨고 화면을 꺼도 유지됩니다.
정품(마이크로소프트) 로그인은 마인크래프트 자바 에디션을 구매한 계정이 필요합니다.
```
(심사자가 써 볼 수 있는 비정품 허용 서버 주소를 하나 준비해 두면 좋습니다.)

**콘텐츠 등급(IARC)**: 앱 종류 "기타/유틸리티". 다른 사용자와 채팅할 수 있으므로 "사용자 간 상호작용(채팅)"에 **예**. 폭력·성적 콘텐츠·도박 등은 앱 자체에 없음.

**타깃 연령층**: 13~15세 이상부터 (아동 포함 안 함). 아동을 포함하면 가족 정책 요건이 붙습니다.

**데이터 보안(Data safety)**
- 데이터를 수집합니까? → **아니요** (개발자 서버로 전송하는 데이터 없음. 기기 안에만 저장하는 데이터는 "수집"이 아님)
- 데이터를 공유합니까? → **아니요**
- 전송 중 암호화 → 예 (인증 서버 HTTPS)
- 삭제 요청 방법 → 앱에서 계정·서버 삭제, 또는 앱 데이터 삭제
- 참고: 사용자가 입력한 마인크래프트 서버로 닉네임·채팅이 가는 것은 사용자가 직접 고른 서비스와의 통신이라 "공유"로 보지 않는 것이 일반적이지만, 화면의 설명을 읽고 판단하세요.

**포그라운드 서비스 신고**
- 유형: 특수 용도(specialUse)
- 설명:
```
사용자가 직접 "접속" 버튼을 눌러 마인크래프트 서버 잠수를 시작하면, 화면을 꺼도 서버 연결(keep-alive 응답)을 유지하기 위해 포그라운드 서비스를 실행합니다. 실행 중에는 항상 알림이 표시되며, 알림의 "끊기" 버튼이나 앱에서 언제든 멈출 수 있습니다. 연결을 끊으면 서비스도 바로 종료됩니다. 다른 서비스 유형(dataSync 등)은 시간 제한이 있어 몇 시간 동안 연결을 유지해야 하는 이 기능에 맞지 않습니다.
```
- 시연 영상(유튜브 일부 공개 링크): ① 서버 접속 버튼 누르기 → ② 알림이 뜸 → ③ 화면 끄기 → ④ 다시 켜도 접속 유지 → ⑤ 알림의 끊기로 종료 (30초~1분)

**뉴스·금융·건강·정부·코로나 앱**: 해당 없음
