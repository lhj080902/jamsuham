**포그라운드 서비스 신고**
- 유형: 특수 용도(specialUse)
- 설명:
```
사용자가 직접 "접속" 버튼을 눌러 마인크래프트 서버 잠수를 시작하면, 화면을 꺼도 서버 연결(keep-alive 응답)을 유지하기 위해 포그라운드 서비스를 실행합니다. 사용자가 잠수 중이던 상태에서 폰이 다시 켜지거나 앱이 업데이트된 경우에만(서버 설정에서 끌 수 있음) 같은 잠수를 이어서 시작합니다. 실행 중에는 항상 알림이 표시되며, 알림의 "끊기" 버튼이나 앱에서 언제든 멈출 수 있습니다. 연결을 끊으면 서비스도 바로 종료됩니다. 다른 서비스 유형(dataSync 등)은 시간 제한이 있어 몇 시간 동안 연결을 유지해야 하는 이 기능에 맞지 않습니다.
```
- 시연 영상(유튜브 일부 공개 링크): ① 서버 접속 버튼 누르기 → ② 알림이 뜸 → ③ 화면 끄기 → ④ 다시 켜도 접속 유지 → ⑤ 알림의 끊기로 종료 (30초~1분)
