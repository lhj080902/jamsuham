# 잠수크래프트 클라우드 서버 — 설치·운영 안내

폰 대신 **서버 컴퓨터가 마인크래프트 서버에 접속해 있는** 방식입니다. 폰을 끄거나 앱을 지워도, 직접 끊거나 서버에서 내보내지 않는 한 계속 접속해 있습니다.
앱과 웹이 같은 잠수를 같이 보고 조작합니다.

```
 폰 앱 ─┐                         ┌─ 마인크래프트 서버 A
        ├─(HTTPS)─ 클라우드 서버 ─┤
 웹 ────┘   (이 프로그램, 24시간)  └─ 마인크래프트 서버 B
```

- 클라우드 서버는 앱과 **같은 엔진(core)** 으로 만들어져 있고 **버전 번호도 앱과 같습니다.** 앱이 업데이트될 때 서버용 파일도 같이 만들어집니다.
- 프로그램 위치: 저장소의 `cloud/` (웹 화면은 `cloud/src/main/resources/web/`)

---

## 1. 준비물
- 24시간 켜 둘 컴퓨터 (윈도우·리눅스·맥 모두 가능)
- **자바 17 이상** — 업로드 키를 만들 때 쓴 Temurin 17 이면 됩니다 (`java -version` 으로 확인)
- 인터넷에 공개하려면 **HTTPS** 가 꼭 필요합니다 → 6번 참고 (집 안에서만 시험할 때는 없어도 됨)
- Mojang 승인을 받은 **client ID** (앱과 같은 값: `9f60141c-29ac-4d71-8fa1-f89e32a085e7`)

메모리는 시험 환경에서 기본 약 230MB, 잠수 하나를 더할 때마다 수 MB 정도였습니다. 실제 서버는 지형 데이터 때문에 더 쓸 수 있으니 여유 있게 잡으세요.

## 2. 받기
GitHub 릴리스(https://github.com/lhj080902/jamsuham/releases)의 최신 빌드에서 **`jamsu-cloud.zip`** 을 받아 원하는 폴더에 풉니다.

```
jamsu-cloud/
  bin/jamsu-cloud        ← 리눅스·맥 실행 파일
  bin/jamsu-cloud.bat    ← 윈도우 실행 파일
  lib/                   ← 프로그램
```

## 3. 처음 실행
압축을 푼 `jamsu-cloud` 폴더에서 실행합니다.

윈도우 (명령 프롬프트):
```bat
bin\jamsu-cloud.bat
```

리눅스·맥:
```bash
bin/jamsu-cloud
```

처음 실행하면 같은 폴더에 **`cloud.properties`**(설정)와 **`data/`**(데이터)가 생깁니다.
1. 창을 닫아 서버를 끄고(Ctrl+C), `cloud.properties` 를 메모장으로 열어 `msClientId=` 뒤에 client ID 를 적습니다.
2. 다시 실행합니다.
3. 그 컴퓨터의 브라우저에서 **http://localhost:8787** 을 열면 웹 화면이 나옵니다.

## 4. 설정 (`cloud.properties`)
| 항목 | 뜻 | 기본값 |
|---|---|---|
| `port` | 웹 주소의 포트 | 8787 |
| `bind` | `127.0.0.1` = 이 컴퓨터 안에서만 / `0.0.0.0` = 같은 공유기의 다른 기기에서도 | 127.0.0.1 |
| `msClientId` | 마이크로소프트 로그인용 client ID (앱과 같은 값) | (비어 있음) |
| `trustProxy` | 앞에 Caddy·Cloudflare 터널이 있으면 true | true |
| `premiumMode` | `allowlist` = premium.txt 의 계정만 / `open` = 로그인한 누구나 | allowlist |
| `maxSessionsPerAccount` | 한 계정이 동시에 잠수할 수 있는 서버 수 | 2 |
| `maxServersPerAccount` | 한 계정이 저장할 수 있는 서버 수 | 20 |
| `maxActiveSessions` | 이 컴퓨터 전체에서 동시에 돌릴 잠수 수 | 200 |
| `maxAccountsPerTarget` | **같은 마인크래프트 서버에** 클라우드에서 동시에 들어갈 계정 수 (0 = 제한 없음) | 3 |
| `targetLimits` | 서버별로 다르게: `주소=수` 를 쉼표로 | (비어 있음) |
| `dataDir` | 데이터 폴더 | data |

설정을 바꾸면 서버를 다시 켜야 적용됩니다.

## 5. 유료(프리미엄) 사용자 관리
`premiumMode=allowlist` 이면 **`data/premium.txt` 에 적힌 계정만** 클라우드 잠수를 쓸 수 있습니다. 이 파일은 저장하면 **바로 반영**됩니다(서버를 끌 필요 없음).

```
# 한 줄에 한 명: 닉네임 또는 UUID, 그 뒤에 만료일(선택)
Steve                       # 기한 없음
Alex 2027-01-31             # 2027년 1월 31일까지
```

명령으로도 넣을 수 있습니다 (서버가 켜져 있어도 됩니다. `cloud.properties` 가 있는 폴더에서 실행).
```bash
bin/jamsu-cloud grant Steve 30
```
```bash
bin/jamsu-cloud revoke Steve
```

- 프리미엄이 아닌 사람이 로그인하면 **닉네임과 UUID** 가 화면에 나옵니다 → 그 닉네임을 받아 premium.txt 에 적어 주면 됩니다.
- 프리미엄이 아닌 계정의 로그인 정보는 서버에 저장하지 않습니다.
- 기간이 끝나면 5분 안에 그 계정의 잠수가 멈춥니다.
- 닉네임은 바뀔 수 있으니 오래 쓸 사람은 UUID 로 적는 것이 안전합니다.

## 6. 인터넷에 공개하기 (HTTPS 필수)
로그인 정보와 채팅이 오가므로 **반드시 HTTPS** 로만 공개하세요. 앱은 `https://` 주소만 받습니다(같은 공유기 안의 `http://192.168.x.x` 는 시험용으로 허용).
`bind=127.0.0.1` 은 그대로 두고 앞에 아래 둘 중 하나를 둡니다.

**방법 A — Cloudflare 터널 (공유기 설정이 필요 없어 집 컴퓨터에 편함)**
도메인을 Cloudflare 에 연결한 뒤 `cloudflared` 를 설치하고 터널의 대상을 `http://localhost:8787` 로 지정합니다.
(Cloudflare 문서: https://developers.cloudflare.com/cloudflare-one/connections/connect-networks/ )

**방법 B — Caddy (도메인 + 공유기 포트 포워딩 80·443)**
`Caddyfile` 한 줄이면 인증서를 자동으로 받아 줍니다.
```
cloud.example.com {
    reverse_proxy 127.0.0.1:8787
}
```
(Caddy 문서: https://caddyserver.com/docs/quick-starts/reverse-proxy )

> 실시간 표시(SSE)를 쓰므로 프록시가 응답을 모아서 보내지 않게 해야 합니다. Caddy·Cloudflare 터널은 기본 설정으로 됩니다. nginx 를 쓰면 `proxy_buffering off;` 가 필요합니다.

## 7. 앱에서 쓰기
1. 앱 **설정 → 클라우드 잠수 (프리미엄)** → 주소에 `https://내주소` 입력 → **확인**
2. 아래 계정 줄의 **연결** → 안내를 읽고 **동의하고 연결**
   (이 계정의 로그인 정보가 클라우드 서버로 넘어가 암호화되어 저장됩니다. 앱 v2.0.0 이상에서 로그인한 계정만 됩니다 — 그 전에 추가한 계정은 계정 관리에서 지우고 다시 로그인한 뒤 연결하세요)
3. 서버 설정에서 **클라우드에서 잠수** 를 켜고 저장 → 목록에 `☁ 클라우드` 가 붙습니다.
4. **시작** 을 누르면 클라우드에 요청이 가고, 채팅 화면에 클라우드의 채팅이 실시간으로 보입니다.

- 모든 사용자의 앱에 주소를 미리 넣으려면 GitHub 저장소 **Variables** 에 `CLOUD_URL` = `https://내주소` 를 등록하면 다음 빌드부터 기본값으로 들어갑니다.
- 클라우드 잠수에서는 아직 **지도·이동·아이템 사용** 을 쓸 수 없습니다. 채팅·명령어·자동완성·서버 메뉴 클릭·접속자·체력·사망 알림·칭호 그림은 됩니다.
- 앱을 안 보는 동안에는 폰이 클라우드와 연결하지 않습니다(배터리·데이터 절약). 그동안의 채팅은 앱을 열면 이어서 받습니다(서버마다 최근 1,500줄).

## 8. 웹에서 쓰기
브라우저에서 주소를 열고 **마이크로소프트 계정으로 로그인** → 화면의 코드를 복사 → 마이크로소프트 페이지에 붙여 넣고 로그인하면 됩니다.
서버 추가·설정·시작·끊기, 채팅, 서버 메뉴 클릭, 접속자·상태 보기가 됩니다. **계정 → 연결 해제(삭제)** 를 누르면 그 계정의 잠수를 모두 끊고 서버에 저장된 정보를 지웁니다.

## 9. "어디서 실행 중인지" 표시와 중복 접속 차단
같은 계정이 같은 마인크래프트 서버에 두 곳에서 들어가면 서로 튕겨 내므로, 먼저 들어간 쪽이 있으면 막습니다.

| 지금 접속 중인 곳 | 다른 곳에서 시작하려 하면 |
|---|---|
| **클라우드** | 폰 앱(직접 잠수): "이미 클라우드에서 실행 중입니다. 그쪽 연결을 해제하고 다시 시도해 주세요" + [클라우드 연결 끊기] 버튼 |
| **폰 앱**(직접 잠수) | 클라우드(웹·앱에서 시작): "이미 앱 · (기기 이름)에서 실행 중입니다. 그쪽 연결을 해제하고 다시 시도해 주세요" |
| **PC 게임 등 다른 클라이언트** | 그쪽이 들어오면 마인크래프트 서버가 클라우드·앱 쪽을 내보냅니다 → 잠수를 멈추고 "다른 클라이언트(PC 게임 등)에서 접속해 끊겼습니다" 로 표시. 30분 안에 다시 시작하면 "지금 시작하면 그쪽 접속이 끊깁니다. 계속할까요?" 를 묻습니다 |

- 웹은 따로 접속하는 매체가 아니라 **클라우드 잠수를 보는 화면**입니다.
- **PC 게임이 들어가는 것 자체는 막을 수 없습니다** (게임은 우리 서버를 거치지 않습니다). 막으려면 PC 쪽 모드(FastPack)가 접속 전에 클라우드에 물어보게 만들어야 합니다 — 아직 없음.
- 폰 앱은 직접 잠수 중인 서버를 1분마다 클라우드에 알립니다. 폰이 갑자기 꺼지면 2분 30초 뒤에 "앱에서 실행 중" 표시가 풀립니다.

## 10. 같은 IP 문제 (여러 사람이 한 마인크래프트 서버에 들어갈 때)
클라우드의 모든 계정은 **이 컴퓨터의 IP 하나**로 나갑니다. 마인크래프트 서버 대부분은 "같은 IP 에서 몇 명까지" 제한이 있어서, 넘기면 부계정으로 처리하거나 IP 를 통째로 막을 수 있습니다.
- `maxAccountsPerTarget` 으로 서버 하나에 들어갈 계정 수를 그 제한보다 낮게 둡니다. 자리가 차면 "지금 이 서버는 클라우드 자리가 모두 찼습니다" 라고 안내합니다.
- 운영진에게 "이 IP 는 여러 사용자가 쓰는 잠수 서비스" 라고 알리고 **허용을 받은 서버**만 `targetLimits=주소=수` 로 늘립니다.
- 계정마다 IP 를 다르게 보이게 하는 방식(프록시)은 넣지 않았습니다. 서버의 제한을 속이는 것이라 규칙 위반이고, 적발되면 사용자 계정이 정지됩니다.
- 한꺼번에 많은 계정이 로그인하면 모장 인증 서버의 요청 제한(429)에도 걸립니다. 서버를 다시 켤 때는 2초 간격으로 차례로 접속합니다.

## 11. 업데이트
1. 서버를 끕니다 (Ctrl+C. 잠수 중이던 서버는 기억해 두었다가 다시 켜면 2초 간격으로 이어서 접속합니다)
2. 새 `jamsu-cloud.zip` 을 풀어 **`bin`·`lib` 폴더를 덮어씁니다.** `cloud.properties` 와 `data/` 는 그대로 둡니다.
3. 다시 켭니다.

켜져 있는 동안 파일을 덮어쓰면 오류가 나니 꼭 끄고 바꾸세요. 앱이 서버보다 새 버전이어도 대부분 동작하지만, 형식이 바뀌는 업데이트 때는 앱이 "클라우드 서버를 업데이트해 주세요" 라고 알려 줍니다.

## 12. 데이터와 보안
```
data/
  master.key        ← 로그인 정보를 암호화하는 키. 절대 공유·업로드하지 마세요
  accounts/         ← 계정 + 암호화된 마이크로소프트 로그인 정보
  servers/          ← 계정별 서버 목록, 잠수 중 표시
  tokens.json       ← 로그인한 기기들 (토큰은 해시만 저장)
  premium.txt       ← 프리미엄 목록
  engine/           ← 버전 변환기 설정
```
- 마이크로소프트 로그인 정보는 `master.key` 로 암호화(AES-256-GCM)해 저장합니다. **`data/` 폴더 전체가 새어 나가면 계정이 위험**하므로 이 컴퓨터의 접근 권한을 잘 관리하세요.
- 채팅은 디스크에 저장하지 않습니다 (메모리에 서버마다 최근 1,500줄. 서버를 끄면 사라짐).
- 사용자가 **연결 해제(삭제)** 를 누르면 그 계정의 로그인 정보·서버 목록·기기 기록을 바로 지웁니다.
- 사용자가 적은 주소로 이 컴퓨터가 대신 접속하므로, 내부망 주소(192.168.x.x 등)와 1024 미만 포트로는 접속하지 않게 막아 두었습니다.

## 13. 컴퓨터를 켜면 자동으로 시작하기
**윈도우**: 작업 스케줄러 → 기본 작업 만들기 → 트리거 "컴퓨터 시작 시" → 동작 "프로그램 시작" 에 `bin\jamsu-cloud.bat`, "시작 위치" 에 `jamsu-cloud` 폴더.

**리눅스 (systemd)**: `/etc/systemd/system/jamsu-cloud.service`
```ini
[Unit]
Description=Jamsucraft Cloud
After=network-online.target

[Service]
WorkingDirectory=/opt/jamsu-cloud
ExecStart=/opt/jamsu-cloud/bin/jamsu-cloud
Restart=always
User=jamsu

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now jamsu-cloud
```

## 14. 유료로 받기 전에 꼭 확인할 것
- **개인정보처리방침**: 클라우드 잠수는 사용자의 로그인 정보를 운영자 서버에 보관합니다. 앱의 방침(`app/src/main/assets/legal/privacy-policy.md`)에 클라우드 항목을 넣어 두었지만, **운영자 이름·서버가 있는 곳·다른 사람의 컴퓨터나 호스팅을 쓰는지(위탁)** 는 실제 상황에 맞게 직접 채워야 합니다. Play 의 "데이터 보안" 신고도 "수집함"으로 바뀝니다.
- **각 마인크래프트 서버의 규칙**: 24시간 잠수·잠수 서비스 접속을 금지하는 서버가 많습니다.
- **결제**: 지금은 premium.txt 를 손으로 고치는 방식입니다. 자동 결제 연동은 아직 없습니다.

## 15. 직접 빌드하기 (개발용)
```bash
./gradlew :cloud:installDist
```
결과: `cloud/build/install/jamsu-cloud/`. 시험은 `tools/corebuild` 의 `harness cloud` 모드(CLAUDE.md "테스트" 참고).
