## 2. 만든 것
### 안드로이드 앱 (`app/`, 엔진은 `core/`)
- 마인크래프트 자바 서버(1.8 ~ 최신)에 폰으로 접속해 잠수·채팅. 화면을 꺼도 유지, 끊기면 자동 재접속, 폰을 다시 켜면 이어서 잠수
- 채팅(색·링크·누르는 버튼·자동완성), 접속 후 자동 명령어, 서버 메뉴 보기·클릭·자동 클릭 규칙
- 체력·허기·사망 알림, 미니맵·조이스틱 이동·웨이포인트, 인벤토리, 접속자 목록
- 서버 리소스팩의 칭호·아이콘을 그림으로 표시 (도스온라인의 보호된 팩까지 확인)
- 설정: 계정 관리, 디자인 3종, 밝기, 한국어·영어, 글자 크기, 데이터 절약 모드, 채팅 기록 30일 보관·내보내기
- 정품(마이크로소프트) 계정만 사용 (비정품 닉네임 접속은 v1.7.1 에서 뺌)
- GitHub 판(앱 안 업데이트 있음) / Play 판(스토어용) 두 가지로 빌드

### 클라우드 잠수 (`cloud/`, v2.0.0~) — 설치·운영은 `docs/CLOUD.md`
- 서버 컴퓨터가 대신 접속해 있어 폰을 꺼도 유지. 앱과 같은 엔진·같은 버전
- **웹 화면**: 로그인, 서버 추가·설정, 시작·끊기, 채팅, 메뉴 열기·클릭, 메뉴 창에서 자동 클릭 규칙 추가, 접속자·상태, **이동**(조이스틱·점프·키보드, 좌표 표시). 폰·태블릿 브라우저에서도 터치로 조작 가능
- **앱 연동**: 설정 → 클라우드 잠수(계정 연결), 서버 설정의 "클라우드에서 잠수" 스위치
- **유료 사용자만**: `data/premium.txt` 에 적은 닉네임 (결제 자동 연동은 아직 없음)
- **중복 접속 차단**: 클라우드 ↔ 폰 앱 서로 막고 "이미 ○○에서 실행 중입니다" 안내. PC 게임에 밀려나면 표시하고 다시 시작할 때 확인
- **같은 IP 문제**: 한 마인크래프트 서버에 들어가는 계정 수 제한(`maxAccountsPerTarget`, 기본 3). 운영진 허용을 받은 서버만 `targetLimits` 로 늘림

### PC 모드 FastPack (`tools/fastpack-mod/`, Fabric 1.21.4, 루나 클라이언트 확인)
- 서버 리소스팩을 나눠 받아 빠르게, 재접속 때 같은 팩은 다시 적용 안 함, 게임을 다시 켜도 유지(0.3.0 — 시험 결과 아직 확인 못 함)

## 3. 확인한 것 / 아직 확인 못 한 것
- **확인함**: 엔진·클라우드 서버·웹 화면은 PC 시험으로 검증 (통신 38개, 웹 23개, 폰·태블릿 터치, 악의적 채팅 한도 10개, 데이터 형식 15개 항목). 앱은 매번 실제 빌드 통과
- **직접 확인이 필요한 것**
  1. 앱 v2.0.0 이상에서 **계정을 지우고 다시 추가** → 로그인 주소가 `login.microsoftonline.com/consumers` 로 시작하는지, 로그인·서버 접속이 되는지 (v1.7.1 은 새 계정 추가에 버그가 있었음)
  2. 클라우드 서버를 실제로 설치해 **웹 로그인(코드 입력 방식)** 과 **앱의 계정 연결** 이 되는지 (이 작업 환경에서는 마이크로소프트 서버에 닿지 않아 시험 못 함)
  3. 앱의 클라우드 화면(연결·시작·채팅·끊기, 폰 잠수 중 클라우드 시작 차단과 그 반대)이 실제 폰에서 되는지 (컴파일과 코드 검토까지만 함)
  4. FastPack 0.3.0 (게임을 다시 켜도 리소스팩 유지)

## 4. 정해 둔 원칙
- 답은 한국어 존댓말, 코드 주석·화면 문구도 한국어
- 코드를 고치면 동작까지 확인하고 전달, 정보는 출처와 함께
- 버전은 `gradle.properties` 의 `jamsuham.version` (주: 구조 변경 / 부: 큰 기능 / 수: 버그·작은 변경)
- 만들지 않기로 한 것: 학교 와이파이 차단 우회, 계정마다 IP 를 바꿔 서버의 부계정 제한을 피하는 기능
- 비밀 값(서명 키·비밀번호)은 저장소에 올리지 않고 GitHub Secrets 에만

## 5. 남은 일
- (사용자) 위 3번의 직접 확인 4가지
- (사용자) 클라우드 서버 공개: HTTPS(Cloudflare 터널 또는 Caddy) → 저장소 변수 `CLOUD_URL` 등록 → 유료로 받기 전에 개인정보처리방침의 운영자·서버 위치 채우기
- 클라우드: 앱의 클라우드 화면에 이동 붙이기(서버 쪽은 준비됨), 지도, 아이템 사용, 웹의 칭호 그림, 앱이 꺼져 있을 때 사망·메뉴 알림, 결제 연동, 운영자용 관리 화면, 도스온라인 운영진에게 보낼 공유 IP 허용 요청 글
- FastPack: 게임 안 설정 창(Mod Menu), 로그를 나만 보이는 채팅으로, PC 접속 전에 클라우드에 물어보기
- 접속자 전체 목록 버튼 (도스온라인의 `/list`·`/glist` 결과 형식이 필요)
- Play 출시: 그래픽 1024×500, 스크린샷, 테스터 12명 14일, 앱 콘텐츠 신고, 개발자 계정 본인 인증 (`docs/PLAYSTORE_PLAN.md`, `docs/store-listing.md`)
- 나중: iOS, 후원·Play 결제
