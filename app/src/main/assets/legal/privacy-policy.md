# 잠수크래프트 개인정보처리방침

시행일: 2026년 11월 27일

"잠수크래프트"(이하 "앱")은 마인크래프트 자바 에디션 서버에 접속해 채팅·잠수를 할 수 있게 해 주는 안드로이드 앱입니다. 앱은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 알려 드립니다.

> 앱은 기본적으로 **이용자의 개인정보를 개발자에게 전송하거나 수집하지 않으며,** 아래 1번의 정보는 모두 이용자의 기기 안에만 저장됩니다.
> 다만 이용자가 직접 **"클라우드 잠수"(선택 기능)** 에 계정을 연결한 경우에 한해, 2-1번에 적은 정보가 클라우드 서버로 전송·보관됩니다.

## 1. 기기에 저장하는 정보와 목적
| 정보 | 목적 | 보관 위치·기간 |
|---|---|---|
| 마이크로소프트·Xbox·마인크래프트 로그인 토큰, 마인크래프트 닉네임·UUID | 정품 계정으로 서버에 접속 | 기기 안 (안드로이드 Keystore 키로 암호화). 계정을 삭제하거나 앱을 지울 때까지 |
| 서버 목록·서버별 설정·자동 명령어·웨이포인트 | 앱 기능 제공 | 기기 안. 이용자가 지우거나 앱을 지울 때까지 |
| 채팅 기록 | 채팅 화면 표시, 이용자가 원할 때 파일로 내보내기 | 기기 안. **30일이 지나면 자동 삭제**, 서버를 지우면 함께 삭제 |
| 보낸 명령어 기록 | 이전 명령어 다시 쓰기(▲▼) | 기기 안 |
| 서버 리소스팩의 글꼴 그림(칭호·아이콘) | 채팅의 칭호·아이콘을 그림으로 표시 | 기기 안. 설정 → 저장 공간에서 비우거나 앱을 지울 때까지 |
| 앱 설정(디자인·언어·글자 크기 등)·마지막으로 잠수하던 서버 | 앱 기능 제공, 폰을 다시 켜거나 앱이 업데이트되면 이어서 접속 | 기기 안 |
| 차단한 사용자 목록(닉네임·UUID), 버리기를 잠근 아이템 목록, 이용 약관에 동의한 기록 | 차단한 사람의 채팅 숨기기, 아이템을 실수로 버리지 않게 하기, 약관 동의 확인 | 기기 안. 이용자가 풀거나 앱을 지울 때까지 |

로그인 토큰과 계정 목록은 클라우드 백업과 새 기기로의 데이터 이전에서 제외됩니다.

## 2. 앱이 연결하는 곳 (제3자)
앱은 기능을 제공하기 위해 아래 곳과 직접 통신합니다. 개발자를 거치지 않습니다.
- **Microsoft·Xbox Live·Mojang 인증 서버**: 정품 계정 로그인과 서버 접속 인증. 각 회사의 개인정보처리방침이 적용됩니다.
  - [Microsoft 개인정보처리방침](https://privacy.microsoft.com/ko-kr/privacystatement)
- **이용자가 입력한 마인크래프트 서버**: 접속하면 닉네임·UUID·채팅 등 마인크래프트 접속에 필요한 정보가 그 서버로 전달됩니다. 서버 운영자의 정책이 적용됩니다.
- **Mojang 스킨 서버**: 접속자 목록의 얼굴 그림을 받아 옵니다.
- **서버가 알려 준 리소스팩 주소**: 접속한 서버가 리소스팩을 보내라고 하면, 그 주소(서버 운영자가 정한 곳)에서 글꼴 설정과 그림만 받아 옵니다. 이 요청에는 이용자 정보를 담지 않습니다. 서버 설정에서 끌 수 있습니다.
- (GitHub 에서 받은 판만) **GitHub**: 새 버전이 있는지 확인하고 업데이트 파일을 받습니다.

앱은 광고나 분석(통계) 도구를 쓰지 않으며, 위 목적 외에 정보를 제3자에게 제공하지 않습니다.

## 2-2. 신고 (이용자가 직접 보내는 경우에만)
앱에서 사용자나 채팅을 신고하면, 신고 내용이 채워진 **메일 작성 화면**이 이용자의 메일 앱에서 열립니다. 앱이 스스로 보내는 것은 없으며, 이용자가 메일 앱에서 보내기를 눌러야 개발자에게 전달됩니다.
- 메일에 담기는 내용: 신고 대상의 닉네임·UUID(알 수 있는 경우), 서버 주소, 신고 사유와 설명, 신고한 채팅 내용, 시각, 앱 버전. 그리고 메일을 보낸 이용자의 메일 주소.
- 목적: 신고 확인, 앱이 악용되는 방식 파악과 기능 개선. 불법으로 보이는 내용은 관계 기관에 알릴 수 있습니다.
- 보관: 확인이 끝나면 지우며, 길어도 1년을 넘기지 않습니다.
- 차단은 이 기기 안에서만 처리되며 어디로도 전송되지 않습니다.

앱 이용 규칙(금지 행위, 신고·차단 방법)은 이용 약관에 적혀 있습니다 (앱의 정보 → 이용 약관).

## 2-1. 클라우드 잠수 (선택 기능 — 이용자가 직접 연결한 경우에만)
**Google Play 에서 받은 앱에는 클라우드 잠수 기능이 없습니다.** 이 항목은 GitHub 에서 받은 앱에서 이용자가 직접 연결한 경우에만 해당합니다.

클라우드 잠수는 이용자의 폰 대신 **클라우드 서버**가 마인크래프트 서버에 접속해 있는 기능입니다. 설정 → 클라우드 잠수에서 계정의 **"연결"** 을 누르고 안내에 동의한 경우에만 아래 정보가 그 클라우드 서버로 전송됩니다. 연결하지 않으면 아무것도 전송되지 않습니다.

| 클라우드 서버에 보관하는 정보 | 목적 | 보관 기간 |
|---|---|---|
| 연결한 계정의 마이크로소프트·Xbox·마인크래프트 로그인 토큰 (암호화 저장), 마인크래프트 닉네임·UUID | 이용자 대신 마인크래프트 서버에 접속 | 이용자가 연결을 해제(모두 지우기)할 때까지 |
| 클라우드 잠수로 설정한 서버의 주소·설정(자동 명령어·메뉴 자동 클릭 규칙 등) | 클라우드 잠수 실행 | 이용자가 서버를 지우거나 연결을 해제할 때까지 |
| 로그인한 기기 표시(기기 모델명 또는 브라우저 종류), 마지막 사용 시각 | 로그인 유지, "어느 기기에서 실행 중인지" 표시 | 90일 동안 쓰지 않으면 자동 삭제, 또는 연결 해제 시 |
| 잠수 중 주고받은 채팅·서버 상태 | 앱·웹 화면에 표시 | 디스크에 저장하지 않음 (메모리에 서버마다 최근 1,500줄, 클라우드 서버를 다시 켜면 사라짐) |
| 이 폰에서 직접 잠수 중인 서버의 주소 (계정을 연결한 경우 1분마다 알림) | 같은 계정이 두 곳에서 동시에 접속하는 것을 막고 "앱에서 실행 중" 표시 | 저장하지 않음 (소식이 끊기면 2분 30초 뒤 삭제) |

- 클라우드 서버는 위 로그인 토큰으로 Microsoft·Xbox Live·Mojang 인증 서버와 이용자가 지정한 마인크래프트 서버에 접속합니다.
- 전송 구간은 HTTPS 로 암호화되며, 로그인 토큰은 클라우드 서버에서 별도의 키로 암호화(AES-256-GCM)해 저장합니다.
- **지우는 방법**: 앱 설정 → 클라우드 잠수 → 계정의 "해제" → "모두 지우기", 또는 웹 화면의 계정 → "연결 해제(삭제)". 누르는 즉시 그 계정의 잠수를 끊고 클라우드 서버에 저장된 정보를 지웁니다.
- 프리미엄(이용 권한)이 없는 계정으로 연결을 시도한 경우, 로그인 토큰은 클라우드 서버에 저장하지 않습니다. 프리미엄 기간이 끝나면 잠수를 멈추고, 그 뒤 7일 동안 프리미엄이 다시 생기지 않으면 저장된 로그인 토큰과 서버 목록을 자동으로 지웁니다.
- 클라우드 서버 주소는 앱 설정에 표시됩니다. 개발자가 운영하는 주소가 아닌 다른 주소(이용자가 직접 입력한 서버)를 쓰는 경우에는 그 서버 운영자의 정책이 적용됩니다.

## 3. 권한
| 권한 | 용도 |
|---|---|
| 인터넷·네트워크 상태 | 서버 접속, 네트워크가 바뀌면 다시 접속 |
| 알림 | 잠수 중 알림(끊기 버튼), 서버 메뉴 알림 |
| 포그라운드 서비스·절전 해제(Wake lock)·Wi-Fi 상태 | 화면을 꺼도 잠수 접속 유지 |
| 부팅 완료 알림 받기 | 폰을 다시 켜거나 앱이 업데이트되면 잠수하던 서버에 이어서 접속 (서버 설정에서 끌 수 있음) |

## 4. 정보 삭제 방법
- 클라우드 잠수에 연결한 계정: 설정 → 클라우드 잠수 → "해제" → "모두 지우기" (클라우드 서버에 저장된 정보 삭제)
- 계정: 앱의 계정 관리에서 삭제
- 서버·채팅 기록: 서버 삭제 (채팅 기록은 30일 뒤 자동 삭제), 설정 → 저장 공간 → 채팅 기록 모두 지우기
- 리소스팩 글꼴 그림: 설정 → 저장 공간 → 그림 글자 캐시 비우기
- 전부: 앱 삭제 또는 안드로이드 설정 → 앱 → 잠수크래프트 → 저장공간 → 데이터 삭제

## 5. 아동
앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 따로 수집하지 않습니다.

## 6. 안전성 확보 조치
- 로그인 토큰은 기기 밖으로 꺼낼 수 없는 안드로이드 Keystore 키(AES-GCM)로 암호화해 저장합니다.
- 클라우드 잠수의 접속 토큰도 같은 방식으로 기기에 암호화해 저장하며, 클라우드 서버와는 HTTPS 로만 통신합니다.
- 인증 서버와의 통신은 암호화된 연결(HTTPS)을 사용합니다. (서버가 정한 리소스팩 주소는 서버에 따라 암호화되지 않은 http 일 수 있으며, 이 통신에는 이용자 정보가 포함되지 않습니다.)
