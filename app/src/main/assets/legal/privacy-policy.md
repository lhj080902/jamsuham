# 잠수크래프트 개인정보처리방침

시행일: 2026년 11월 21일

"잠수크래프트"(이하 "앱")은 마인크래프트 자바 에디션 서버에 접속해 채팅·잠수를 할 수 있게 해 주는 안드로이드 앱입니다. 앱은 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 알려 드립니다.

> 앱은 **개발자가 운영하는 서버가 없으며, 이용자의 개인정보를 개발자에게 전송하거나 수집하지 않습니다.** 아래 정보는 모두 이용자의 기기 안에만 저장됩니다.

## 1. 기기에 저장하는 정보와 목적
| 정보 | 목적 | 보관 위치·기간 |
|---|---|---|
| 마이크로소프트·Xbox·마인크래프트 로그인 토큰, 마인크래프트 닉네임·UUID | 정품 계정으로 서버에 접속 | 기기 안 (안드로이드 Keystore 키로 암호화). 계정을 삭제하거나 앱을 지울 때까지 |
| 비정품(오프라인) 닉네임 | 비정품 서버 접속 | 기기 안. 계정을 삭제하거나 앱을 지울 때까지 |
| 서버 목록·서버별 설정·자동 명령어·웨이포인트 | 앱 기능 제공 | 기기 안. 이용자가 지우거나 앱을 지울 때까지 |
| 채팅 기록 | 채팅 화면 표시, 이용자가 원할 때 파일로 내보내기 | 기기 안. **30일이 지나면 자동 삭제**, 서버를 지우면 함께 삭제 |
| 보낸 명령어 기록 | 이전 명령어 다시 쓰기(▲▼) | 기기 안 |

로그인 토큰과 계정 목록은 클라우드 백업과 새 기기로의 데이터 이전에서 제외됩니다.

## 2. 앱이 연결하는 곳 (제3자)
앱은 기능을 제공하기 위해 아래 곳과 직접 통신합니다. 개발자를 거치지 않습니다.
- **Microsoft·Xbox Live·Mojang 인증 서버**: 정품 계정 로그인과 서버 접속 인증. 각 회사의 개인정보처리방침이 적용됩니다.
  - [Microsoft 개인정보처리방침](https://privacy.microsoft.com/ko-kr/privacystatement)
- **이용자가 입력한 마인크래프트 서버**: 접속하면 닉네임·UUID·채팅 등 마인크래프트 접속에 필요한 정보가 그 서버로 전달됩니다. 서버 운영자의 정책이 적용됩니다.
- **Mojang 스킨 서버**: 접속자 목록의 얼굴 그림을 받아 옵니다.
- (GitHub 에서 받은 판만) **GitHub**: 새 버전이 있는지 확인하고 업데이트 파일을 받습니다.

앱은 광고나 분석(통계) 도구를 쓰지 않으며, 위 목적 외에 정보를 제3자에게 제공하지 않습니다.

## 3. 권한
| 권한 | 용도 |
|---|---|
| 인터넷·네트워크 상태 | 서버 접속, 네트워크가 바뀌면 다시 접속 |
| 알림 | 잠수 중 알림(끊기 버튼), 서버 메뉴 알림 |
| 포그라운드 서비스·절전 해제(Wake lock)·Wi-Fi 상태 | 화면을 꺼도 잠수 접속 유지 |

## 4. 정보 삭제 방법
- 계정: 앱의 계정 관리에서 삭제
- 서버·채팅 기록: 서버 삭제 (채팅 기록은 30일 뒤 자동 삭제)
- 전부: 앱 삭제 또는 안드로이드 설정 → 앱 → 잠수크래프트 → 저장공간 → 데이터 삭제

## 5. 아동
앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 따로 수집하지 않습니다.

## 6. 안전성 확보 조치
- 로그인 토큰은 기기 밖으로 꺼낼 수 없는 안드로이드 Keystore 키(AES-GCM)로 암호화해 저장합니다.
- 인증 서버와의 통신은 암호화된 연결(HTTPS)을 사용합니다.
